⚙️ One-Time Setup (Python)

You only need to do this once. Requires Python 3.9+ (free — python.org).

1

Install Python libraries

Open Terminal (Mac/Linux) or Command Prompt (Windows) and run:

pip install requests beautifulsoup4 playwright openpyxl pandas tqdm lxml
2

Install Playwright browser

This lets the scraper handle JavaScript-rendered pages on harness.com.au:

playwright install chromium
3

Download the scraper files

Place harness_scraper.py and horses.txt in a folder, e.g. ~/harness-data/

4

Run your first scrape

cd ~/harness-data
python harness_scraper.py --horse goodtime-oscar --playwright
# → Creates output/goodtime-oscar.xlsx
💡 No-code alternative: If Python feels too complex, try Octoparse (free tier) or ParseHub — both are visual point-and-click scrapers that can export to CSV/Excel. However, they're less powerful for the structured multi-tab output you want. The Python approach will give you far better results.

🚀 Command Examples

Single Horse

python harness_scraper.py --horse goodtime-oscar --playwright
# Output: output/goodtime-oscar.xlsx (6 tabs)

Trainer

python harness_scraper.py --trainer tammy-langley --playwright
# Output: output/trainer_tammy-langley.xlsx

Driver

python harness_scraper.py --driver grace-jones --playwright
# Output: output/driver_grace-jones.xlsx

Bulk — Many Horses at Once

Edit horses.txt — one URL slug per line:

# horses.txt
goodtime-oscar
my-mate-luke
fast-freddie
another-horse-slug

Then run:

python harness_scraper.py --bulk horses.txt --type horse --out my_horses --playwright
# → Creates individual .xlsx per horse + _combined_results.csv

🔍 Finding the URL Slug

The "slug" is the part of the URL after /horse/, /trainer/, or /driver/. 

URL:
harness.com.au/horse/goodtime-oscar

Slug = goodtime-oscar

Use: --horse goodtime-oscar
URL:
harness.com.au/trainer/tammy-langley

Slug = tammy-langley

Use: --trainer tammy-langley
⚠️ Be respectful: The scraper waits 1.5 seconds between requests. Don't scrape hundreds of pages in one go — space out large bulk runs. This keeps harness.com.au happy and reduces the chance of being blocked.
